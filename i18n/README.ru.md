# OrganoidIntelligence

OrganoidIntelligence — это дорожная карта, соединяющая мозговые органоиды, organ-on-chip инженерию, MEA-интерфейсы и замкнутые wetware computing системы.

- Сайт: [ideas.onlyideas.art](https://ideas.onlyideas.art)
- Репозиторий: [github.com/lachlanchen/OrganoidIntelligence](https://github.com/lachlanchen/OrganoidIntelligence)
- Связанный проект: [OrganoidVision](https://github.com/lachlanchen/OrganoidVision)
