# OrganoidIntelligence

OrganoidIntelligence est une feuille de route pour relier les organoïdes cérébraux, l'ingénierie organ-on-chip, les interfaces MEA et le calcul biologique en boucle fermée.

- Site: [ideas.onlyideas.art](https://ideas.onlyideas.art)
- Dépôt: [github.com/lachlanchen/OrganoidIntelligence](https://github.com/lachlanchen/OrganoidIntelligence)
- Projet compagnon: [OrganoidVision](https://github.com/lachlanchen/OrganoidVision)
